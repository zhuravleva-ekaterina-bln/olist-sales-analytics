# Olist E-Commerce Sales Analysis

## Projektübersicht

In diesem Projekt werden Verkaufsdaten des brasilianischen E-Commerce-Unternehmens Olist analysiert und mit Microsoft Power BI visualisiert.

Ziel ist es, einen übersichtlichen Bericht zu erstellen, der wichtige Verkaufskennzahlen, zeitliche Entwicklungen und regionale Unterschiede darstellt.

## Datengrundlage

**Datensatz:** Brazilian E-Commerce Public Dataset by Olist  
**Quelle:** [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Der Datensatz enthält Informationen zu Bestellungen, Produkten, Kunden, Zahlungen und weiteren Aspekten des Onlinehandels.

## Verwendete Tools

- Microsoft Power BI Desktop
- Power Query zur Datenaufbereitung
- DAX zur Berechnung von Kennzahlen

## Dashboard und Kennzahlen

Das Dashboard enthält folgende Analysen:

- Gesamtumsatz
- Anzahl gelieferter Bestellungen
- Durchschnittlicher Bestellwert
- Umsatzentwicklung im Zeitverlauf
- Umsatz nach Produktkategorien
- Umsatz nach brasilianischen Bundesstaaten
- Interaktive Datumsfilterung

## Ergebnisse

Das Dashboard zeigt einen Gesamtumsatz von rund 13,22 Millionen BRL und etwa 96.000 gelieferte Bestellungen. Der durchschnittliche Bestellwert beträgt rund 137 BRL.

Die Visualisierungen ermöglichen es, die Umsatzentwicklung sowie Unterschiede zwischen Produktkategorien und Regionen zu untersuchen.
